    How it works
    
The terminal client checks your invitation, adds fresh randomness and verifies the result. Only public contribution data is uploaded. The coordinator verifies it again before acceptance.

    
The client handles the queue. Press Ctrl+C to stop; run the same command to resume. Accepted contributions are skipped.

    
Public work and receipts stay in ~/.local/share/spr-ceremony/work. Neither the client nor your operating system guarantees memory erasure.
