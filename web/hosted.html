    Trust & verification
    
You trust this host’s code and your computer. A compromised host or extension could steal randomness. For an independently checked build, use the terminal client. Neither client guarantees memory erasure.

    
Browser storage holds public work and receipts. Your invitation stays in memory. Save your receipts: storage can be evicted. Receipt inclusion and final transcript verification are separate checks.
