What happens on this page?

A worker runs the pinned Go contribution engine through WebAssembly. It checks the input hash, generates randomness using the browser’s cryptographic random source, computes the update, and verifies it before exporting.

The page downloads public parameters and code. It uploads nothing. This prototype does not save the sampled secret or guarantee that browser or operating-system memory has been erased.

Cancel stops the worker. Rerunning starts a fresh contribution. Resumable transfers, queue reservations, and coordinator receipts are not part of this rehearsal.
